# Docs

Where this project keeps what the skills read and write. Paths are relative to
the repo root.

- Requirements: `docs/requirements.md`: use cases and requirements, with their IDs.
- Architecture: `docs/architecture.md`: components, processes, request flow, data and the
  invariants, each with the test that checks it.
- Setup: `docs/setup.md`: the steps to run each harness in a profile, for a user.
- Decisions: `docs/decisions.md`: numbered entries (D1, D2, …), under "Decisions".
- Glossary: `docs/glossary.md`: the project's words, in the format of the
  `domain-modeling` skill's GLOSSARY-FORMAT.md.
- Kept out of the repo: secrets, hosts, accounts and personal data. They live in
  untracked local notes (`AGENTS.local.md`).
